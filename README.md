## 🚀 Proiecte / Projects

### 1. [FossilSoloMCP](https://relupercan.github.io/proiecte/fossil-scm-mcp/)
* **RO:** Server MCP (Model Context Protocol) stdio complet pentru integrarea sistemului de control al versiunilor Fossil SCM în asistenți AI (Antigravity, Claude Desktop, Cursor etc.).
* **EN:** Full-featured stdio MCP (Model Context Protocol) server integrating Fossil SCM version control with modern AI assistants.
* **Depozit / Repository:** [ReluPercan/FossilSoloMCP](https://github.com/ReluPercan/FossilSoloMCP)

### 2. [AllCharsAHK](https://relupercan.github.io/proiecte/allchars-ahk/)
* **RO:** Utilitar de productivitate tastatură pentru Windows (AutoHotkey v2) inspirat din clasicul AllChars, permițând tastarea rapidă a caracterelor speciale și diacriticelor românești.
* **EN:** Keyboard productivity utility for Windows (AutoHotkey v2) inspired by the classic AllChars, enabling instant typing of Romanian diacritics and special Unicode symbols.
* **Depozit / Repository:** [ReluPercan/AllCharsAHK](https://github.com/ReluPercan/AllCharsAHK)
