AllCharsAHK

Motor universal de tastare caractere Unicode și diacritice pentru Windows

📋 Rezumat

AllCharsAHK este un utilitar scris nativ în AutoHotkey v2, inspirat din conceptul clasic al tastei Compose și din popularul program istoric AllChars.

Pe orice tastatură fizică (de exemplu US English sau tastaturi pentru programare), introducerea caracterelor speciale precum diacriticele ă, î, ș, ț, â sau simbolurile tipografice (« », —, ©, €, ±) necesită în mod tradițional comutarea deranjantă a limbii de sistem (Alt+Shift) sau memorarea codurilor Alt+Numpad.

AllCharsAHK rezolvă elegant această problemă: apeși scurt o tastă de declanșare (de exemplu Right Ctrl sau Right Shift), tastezi o secvență mnemotehnică intuitivă de 2 caractere, iar caracterul dorit este inserat instantaneu.

⚡ Zero Conflicte cu Comenzile Windows

Modul Compose se activează exclusiv la apăsarea și eliberarea scurtă a tastei de declanșare fără a ține alte taste apăsate simultan. Comenzile rapide standard din Windows (precum Ctrl+C, Ctrl+V, Ctrl+A) continuă să funcționeze 100% normal în orice aplicație.

⌨️ Tastare & Exemple de Configurare

Tot comportamentul scriptului este dictat de fișierul text AllCharsAHK.cfg. Mapările au o sintaxă extrem de simplă: [activator] [taste] -> [rezultat].

Iată un extras reprezentativ din fișierul canonic de configurare:

# Diacritice (Right Ctrl / Right Shift)
rc a -> ă
rs a -> Ă
rc s -> ș
rs s -> Ș

# Ghilimele standard și linie de dialog
lc , -> „
ls ' -> ”
ls - -> —

# Simboluri uzuale, valutare și matematice
rc e -> €
lc 0 -> °
ls = -> ±
ls . -> →

Tasta activator se apasă și se eliberează scurt, după care se apasă tasta asociată. Iată cum se traduc aceste mapări în utilizarea practică:

ș / Ș Right Ctrl (sau Right Shift) urmat de s rc s -> ș  /  rs s -> Ș Diacritică (s cu virgulă dedesubt)

AllCharsAHK

Universal Unicode and diacritics typing engine for Windows

📋 Summary

AllCharsAHK is a utility natively written in AutoHotkey v2, inspired by the classic Compose key concept and the renowned legacy tool AllChars.

On standard physical keyboards (such as US English programming layouts), entering special characters like diacritics ă, î, ș, ț, â or typographic glyphs (« », —, ©, €, ±) typically requires disruptive system language switching (Alt+Shift) or memorizing Alt+Numpad codes.

AllCharsAHK makes this effortless: briefly tap and release a trigger key (such as Right Ctrl or Right Shift), type an intuitive 2-character mnemonic sequence, and the desired glyph appears immediately in your target document.

⚡ Zero Conflicts with Standard Windows Shortcuts

Compose mode engages exclusively when you briefly tap and release the trigger key without holding any other keys. Native system shortcuts (such as Ctrl+C, Ctrl+V, Ctrl+A) remain 100% unaffected and function normally across all applications.

⌨️ Typing & Configuration Examples

All script behavior is defined in the plain text file AllCharsAHK.cfg. Bindings follow a straightforward syntax: [trigger] [keys] -> [replacement].

Here is a representative snippet from the canonical configuration file:

# Diacritics (Right Ctrl / Right Shift)
rc a -> ă
rs a -> Ă
rc s -> ș
rs s -> Ș

# Standard quotes and em dash
lc , -> „
ls ' -> ”
ls - -> —

# Mathematical & Common Symbols
rc e -> €
lc 0 -> °
ls = -> ±
ls . -> →

The trigger key is tapped and released briefly, followed by the associated key. Here is how these bindings translate into day-to-day typing:

Glyph Physical Keystrokes Line in AllCharsAHK.cfg Description / Purpose
ă / Ă Right Ctrl (or Right Shift) followed by a rc a -> ă  /  rs a -> Ă Diacritic (a with breve)
ș / Ș Right Ctrl (or Right Shift) followed by s rc s -> ș  /  rs s -> Ș Diacritic (s with comma below)
„ Left Ctrl followed by , (comma) lc , -> „ Opening low double quotation mark
” Left Shift followed by ' (apostrophe) ls ' -> ” Closing right double quotation mark
— Left Shift followed by - (minus) ls - -> — Em dash punctuation mark
€ Right Ctrl followed by e rc e -> € Euro currency symbol
° Left Ctrl followed by digit 0 lc 0 -> ° Degree symbol (temperature / angle)
± Left Shift followed by = ls = -> ± Plus-minus mathematical symbol
→ Left Shift followed by . (period) ls . -> → Rightwards pointing arrow

🏁 Quick Start Guide

Download the archive, extract it, and create (if needed) or edit the AllCharsAHK.cfg configuration file to suit your needs, then:

  • Option A (Pre-compiled Executable): Download the ready-to-run package from GitHub Releases and run AllCharsAHK.exe (no prior installation required).
  • Option B (AHK Source Code): Make sure you have AutoHotkey v2 installed and double-click AllCharsAHK.ahk.
