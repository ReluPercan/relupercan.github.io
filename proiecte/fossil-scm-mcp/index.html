fossil-scm-mcp

Server Model Context Protocol (MCP) autonom și headless pentru Fossil SCM

📋 Rezumat

fossil-scm-mcp (cunoscut și ca FossilSoloMCP) conectează asistenții de programare bazați pe AI (Claude Desktop, Antigravity, Cursor, etc.) direct cu sistemul distribuit de control al versiunilor Fossil SCM. Serverul funcționează complet decuplat, permițând agenților inteligenți să inspecteze, să comită, să gestioneze ramuri, să vizualizeze diferențe și să acceseze documentația wiki direct prin conversație.

💡 Parametru CWD Dinamic

Toate uneltele acceptă un parametru opțional cwd. Aceasta permite unui singur proces de server să lucreze simultan pe depozite diferite fără reconfigurare sau repornire.

⚡ Instalare Rapidă

Instalare prin managerul oficial de pachete Python (pip sau uv):

pip install fossil-scm-mcp

Sau rulare directă, fără instalare prealabilă, folosind uvx:

uvx fossil-scm-mcp

🤖 Configurare pentru Asistenți AI

Exemplu de configurare în fișierul JSON al clientului MCP (de ex. claude_desktop_config.json):

{
  "mcpServers": {
    "fossil-scm": {
      "command": "uvx",
      "args": ["fossil-scm-mcp"]
    }
  }
}

🛠️ Categorii de Unelte Disponibile

Serverul pune la dispoziția asistenților AI o suită modulară de unelte organizate pe arii funcționale:

  • Gestiune Depozit: inițializare depozit nou, clonare, deschidere și închidere check-out, configurare setări depozit.
  • Inspecție & Stare: verificare status curent, diferențe (diff), istoric comiteri (timeline) și inspecție artefacte.
  • Operațiuni pe Fișiere: adăugare, mutare/redenumire, eliminare, reconciliere automată și comitere (commit/revert).
  • Ramuri, Taguri & Fuziuni: creare și gestionare ramuri de lucru, etichetare versiuni, fuzionare (merge), actualizare și stash.
  • Mentenanță & Curățare: scanarea fișierelor netrackuite și curățarea automată a spațiului de lucru.
  • Wiki & Tichetare: citire, creare și actualizare pentru documentația wiki internă și sistemul nativ de tichete (issues).

Pentru lista exhaustivă a comenzilor, parametrii fiecărei unelte și exemple de utilizare, consultați Manualul Tehnic Complet.

fossil-scm-mcp

Autonomous, headless Model Context Protocol (MCP) server for Fossil SCM

📋 Summary

fossil-scm-mcp (also known as FossilSoloMCP) seamlessly bridges AI coding assistants (Claude Desktop, Antigravity, Cursor, etc.) with the Fossil SCM distributed version control system. Operating entirely headless, it empowers AI agents to inspect repositories, commit changes, manage branches, review diffs, and edit wiki/tickets directly through standard conversational workflows.

💡 Dynamic CWD Parameter

All tools support an optional cwd argument. This allows a single running server instance to operate across multiple repositories concurrently without restarting.

⚡ Quick Installation

Install via the standard Python package manager (pip or uv):

pip install fossil-scm-mcp

Or run on-the-fly without prior installation using uvx:

uvx fossil-scm-mcp

🤖 AI Assistant Configuration

Configuration snippet for your MCP client configuration file (e.g. claude_desktop_config.json):

{
  "mcpServers": {
    "fossil-scm": {
      "command": "uvx",
      "args": ["fossil-scm-mcp"]
    }
  }
}

🛠️ Functional Tool Categories

The server equips AI assistants with a modular suite of tools structured across core functional areas:

  • Repository Management: repository initialization, cloning, opening/closing check-outs, and database configuration.
  • Status & Inspection: working copy status, diff generation, timeline history, and historical file inspection.
  • Working Copy Operations: adding, moving, removing, batch tracking, committing changes, and reverting modifications.
  • Branches, Tags & Merges: branch management, version tagging, merging, updating workdirs, and stashing.
  • Maintenance & Cleanup: untracked file identification and safe working tree cleaning.
  • Wiki & Issue Tracking: full lifecycle management for internal project wiki pages and native bug tracking tickets.

For the exhaustive list of specific tool commands, arguments, and practical examples, refer to the Technical Manual.
